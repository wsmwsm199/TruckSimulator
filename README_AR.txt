Truck Simulator Mobile V3
=========================
نسخة متقدمة من اللعبة:
- عالم 3D موسع
- جبال وأشجار ومبانٍ
- شاحنة ومقطورة
- حركة مرور AI
- كاميرتان: خلفية/قيادة
- دورة ليل ونهار
- محطة وقود
- مهمة توصيل ومكافأة
- تحكم لمس وكيبورد

لبناء APK:
1) npm install
2) npx cap add android
3) npx cap sync android
4) npx cap open android
5) في Android Studio: Build > Build APK(s)

ملاحظة: Three.js ما زالت تُحمّل من CDN في game.js. لجعل اللعبة تعمل 100% بدون إنترنت، يجب وضع نسخة three.module.js محليًا داخل www/lib وربطها محليًا.
