طريقة بناء APK من الهاتف فقط:
1) أنشئ مستودعًا جديدًا في GitHub باسم TruckSimulator.
2) ارفع محتويات هذا المجلد إلى المستودع (وليس ملف ZIP فقط).
3) تأكد أن الملف .github/workflows/build-apk.yml موجود.
4) افتح تبويب Actions.
5) اختر Build Android APK.
6) اضغط Run workflow.
7) بعد نجاح البناء افتح نتيجة العملية ثم Artifacts.
8) نزّل Truck-Simulator-APK.zip، فك الضغط وستجد app-debug.apk.
9) ثبّت APK على الهاتف. قد يطلب Android السماح بالتثبيت من هذا المصدر.

هذه APK تجريبية (debug)، وليست APK موقعة للنشر على Google Play.
